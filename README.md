# Bin-Go Admin Dashboard

An incident reporting and waste management tracking dashboard designed for streamlined oversight of municipal garbage collection and sanitation teams.

Built to oversee live reports, this dashboard features interactive mapping for incident locations, real-time KPI tracking, and ticketing workflows to ensure clean and safe communities.

### Tech Stack
- **Framework:** Next.js 16.3 (App Router)
- **UI & Styling:** React 19 + Tailwind CSS v4
- **Animation:** Framer Motion
- **Maps:** Leaflet & React-Leaflet
- **Icons:** Lucide React
- **Backend/Data:** Supabase
