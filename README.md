# Bin'Go

Bin'Go is a smart waste collection platform that makes keeping a community clean simple, transparent, and easy to track. Residents can report waste issues and follow collection trucks live, while barangay administrators manage reports, schedules, and drivers from a single, clean dashboard.

I built Bin'Go from the ground up because I believe waste management shouldn't be guesswork. People deserve to know when their garbage is being collected, and the people running collection operations deserve tools that actually help them respond. As the builder and owner of this project, I designed and developed every part of it myself, from the public website to the admin portal, with one goal in mind: make community sanitation effortless for everyone involved.
